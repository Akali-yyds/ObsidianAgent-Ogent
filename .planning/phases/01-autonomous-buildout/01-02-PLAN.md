<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model text → structured parser | Untrusted provider output is interpreted as JSON and validated |
| orchestrator step → next step context | Step output becomes trusted input for downstream runtime logic |
| pipeline runtime → UI/event consumers | Progress and failure state crosses into later rendering code |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-01 | T | `src/agents/structured-output.ts` | mitigate | Parse raw model text inside a single helper, validate with Ajv, and reject schema-invalid payloads rather than mutating them into shape |
| T-01-02-02 | R | `src/agents/orchestrator.ts` progress stream | mitigate | Emit explicit step-state transitions and terminal failure events so later UI can show the real execution path and retry exhaustion |
| T-01-02-03 | D | `src/agents/structured-output.ts` retry loop | mitigate | Hard-cap repair attempts at one and propagate a terminal error object after retry exhaustion |
</threat_model>
