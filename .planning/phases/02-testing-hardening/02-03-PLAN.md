<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted session JSON → recovery logic | Corrupted disk data crosses into runtime state restoration |
| pack JSON/provider config → runtime/view | Misconfigured or placeholder credentials cross from pack files into execution and user-facing errors |
| desktop/mobile environment → pack availability | Platform capability determines whether grounded-research packs can be safely surfaced |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | I | `src/main.ts` / `src/sessions.ts` | mitigate | Preserve corrupted session data as backup and surface recovery visibly so data loss is detectable and reviewable. |
| T-02-10 | T | `src/packs/loader.ts` | mitigate | Reject placeholder or incomplete provider config before execution so tampered pack files cannot masquerade as valid runtime input. |
| T-02-11 | D | `src/packs/runtime.ts` / `src/view.ts` | mitigate | Keep provider/network failures fail-loud with actionable copy and no auto-retry per D-09, preventing hidden retry loops or misleading success states. |
| T-02-12 | E | `src/view.ts` mobile gating | mitigate | Preserve unsupported-pack hide-and-recover behavior on mobile per D-11 so restricted environments cannot enter unsafe multi-agent flows. |
</threat_model>
