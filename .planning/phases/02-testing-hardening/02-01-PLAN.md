<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test runner → mocked Obsidian seam | Untrusted fixture inputs cross into filesystem-like behaviors during regression tests |
| pack JSON fixture → loader validation | Malformed pack definitions must not bypass validation in tests |
| deterministic provider fake → runtime assertions | Simulated model outputs must not hide invalid retry or verification flows |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | T | `tests/packs/loader.test.ts` | mitigate | Assert invalid pack JSON and current loader guarantees are rejected or preserved so tampered pack definitions cannot silently execute. Placeholder-provider rejection is hardened later in Plan 02-03. |
| T-02-02 | R | `tests/agents/orchestrator.test.ts` | mitigate | Assert ordered event emission so failed or skipped runtime steps cannot be misrepresented in later reporting. |
| T-02-03 | D | `vitest.config.ts` / `tests/setup.ts` | mitigate | Keep tests deterministic with mocked Obsidian and provider seams per D-04 to prevent flaky dependency-driven failures from masking regressions. |
| T-02-04 | I | `tests/sessions.test.ts` | mitigate | Cover persistence boundaries with file callback fakes so corrupted reads cannot silently erase session state without a failing test. |
</threat_model>
